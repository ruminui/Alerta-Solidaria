# Seguridad y divulgación responsable

Este repositorio contiene un **piloto local de investigación**, no una plataforma operativa para emergencias. No instales ni expongas el backend públicamente sin una auditoría profesional, infraestructura, moderación y un acuerdo con protección civil.

Para avisar de un fallo, **no publiques credenciales, coordenadas exactas, datos de personas o detalles que permitan ataques** en issues públicos. Contactá primero en privado al propietario del repositorio por un canal autorizado o utilizá GitHub Private Vulnerability Reporting si está habilitado en la sección Security. No hay en este momento equipo de respuesta 24/7 ni SLA de seguridad.

Riesgos conocidos: autenticación y rate limiting diseñados sólo para pruebas, sesiones en navegador, SQL local con ubicaciones exactas, registros de usuarios no moderados, ausencia de filtrado automático exhaustivo, feeds sísmicos posteriores al evento, falta de canal de avisos anticipados. Ver `docs/SEGURIDAD_Y_PRIVACIDAD.md`.

Si necesitás rescate **no utilices la app como canal de auxilio**: contactá al servicio oficial de emergencias de tu país.
