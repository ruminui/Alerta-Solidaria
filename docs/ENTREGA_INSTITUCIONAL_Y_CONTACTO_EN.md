# Institutional delivery: allowed channels and receipts

Current state 2026-10-10: GitHub public MIT source; manufacturer submissions not sent; no Apple/Samsung agreement or ticket ID.

APPLE: The policy at https://www.apple.com/legal/intellectual-property/policies/ideas.html rejects unsolicited entire proposals and code. Use https://www.apple.com/feedback/iphone/ for focused existing-product feedback or https://developer.apple.com/feedback-assistant/ for one actionable iOS API or feature enhancement. Do not attach ZIP or detailed source unless invited. Preserve official Feedback Assistant ID.

SAMSUNG: Feature suggestions belong in Samsung Members https://www.samsung.com/ar/apps/samsung-members/ subject to account/region availability. A generic developer-support mailbox is not evidence of authorized reception. Do not transmit the project as unsolicited OEM source.

Status vocabulary: PREPARED means a public repo exists; SUBMITTED needs authenticated official receipt; ACKNOWLEDGED needs explicit vendor confirmation; IN_REVIEW needs vendor notice; PARTNERSHIP requires written agreement.

If an authenticated, authorized contact invites a technical submission: send public URL, MIT license, safety status, OEM dossier, platform playbook, CI evidence, test gates, explicit non-certification, and provenance. Record UTC date, channel and submission ID in docs/REGISTRO_ENTREGA.csv. Never contact press/security-abuse inboxes for general pitches.
