# Solicitud concreta de mejora para Galaxy / One UI

**Asunto:** Galaxy — comprobar y explicar mejor las alertas de emergencia durante viajes

Tras el terremoto del 9 de octubre de 2026 en Panamá, observamos que a los viajeros les cuesta verificar si las alertas sísmicas y gubernamentales están disponibles para su operador, región o roaming. Solicitamos una sección One UI clara que muestre capacidad real del dispositivo, pruebas de notificación cuando la autoridad lo autorice, compatibilidad con accesibilidad y guías locales traducidas. Las alertas oficiales deben seguir teniendo prioridad sobre apps comunitarias; no se deben prometer avisos anticipados fuera de las regiones compatibles. Esta comunicación es feedback de una función existente, no una oferta no solicitada de proyecto o código.

Enviar desde la app Samsung Members, sección Comunidad/Comentarios (según región y dispositivo): https://www.samsung.com/ar/apps/samsung-members/.
